# Contributing to GFDS

Issues are not enabled on this fork; report reproducible problems of GFDS itself in the [upstream issue tracker](https://github.com/mxd45za/GFDS2026/issues). Include the input file, build and run commands, GFDS version or commit, compiler, CUDA, MPI, operating system, CPU, GPU, and complete error output. Include the CPU-mode result when available.

Keep pull requests focused on one change. Changes that affect numerical results should include a reproducible case and a CPU/GPU comparison. Update user instructions when inputs, outputs, build steps, or supported behavior change.

Do not upload confidential data, proprietary source code, unrelated generated files, or compiled binaries. Confirm that submitted material may be distributed under [LICENSE.md](LICENSE.md).

For questions about a planned contribution, open a draft pull request.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) when participating in the project.
