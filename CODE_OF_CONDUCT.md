# Code of Conduct

Be respectful and professional in repository issues, pull requests, discussions, documentation, and other project spaces. Technical disagreements should focus on evidence and reproducible results.

Harassment, discrimination, threats, personal attacks, disruptive behavior, publication of private information, and submission of material that violates another party's rights are not accepted.

Project maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when required.

Report conduct concerns privately through the [GitHub report-abuse form](https://github.com/contact/report-abuse).

This code is based on the [Contributor Covenant, version 2.0](https://www.contributor-covenant.org/version/2/0/code_of_conduct.html).
